# Interactive Resume Builder

A responsive and interactive **Resume Builder** developed as Task 29 of the Veda Technology Web Development Internship.

The application allows users to enter their personal, education, and experience details through a form and instantly see the formatted resume in a live preview.

## Features

- Personal information form
- Professional summary section
- Dynamic education entries
- Dynamic experience entries
- Add and remove education records
- Add and remove experience records
- Real-time live resume preview
- Responsive design for desktop, tablet, and mobile
- Print-friendly resume layout
- Save the resume as PDF using the browser's print dialog
- Clear/reset resume functionality
- Input sanitization for safer preview rendering

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser Print API
